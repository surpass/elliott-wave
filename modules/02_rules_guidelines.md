# 模块02 · 规则、准则与研判纪律

> 来源：第二章（印刷p53-98 / PDF p80-125）

## 一、规划浪的规则与准则（原文清单，PDF p110）

**规则（不容违反）：**
- 浪3总是细分成一个推动浪
- 浪5总是细分成一个推动浪或者一个斜纹浪
- 浪2总是细分成锯齿形、平台形或联合形调整浪
- 浪4总是细分成锯齿形、平台形、三角形或联合形调整浪
- **浪2永远不会运动过浪1的起点**
- **浪3总是运动过浪1的终点**
- **浪3永远不会是最短的一浪**
- **浪1、3、5不会都是延长浪**
- （外加推动浪核心规则）**浪4不会进入浪1的价格区域（不重叠）**

**准则（典型非必然）：**
- 浪4几乎总是呈现出与浪2不同的调整模式（交替）
- 浪2通常是锯齿形或锯齿形联合；浪4通常是平台形、三角形或平台形联合
- 浪5有时不创新高（**缩短/Truncation**）
- 浪5常在"浪3终点起、平行于浪2-浪4连线"的趋势线附近结束
- 浪3的中心位置几乎总具有同等时期最陡的斜率（有时浪1早期更陡）
- 浪1、3、5中通常有一个延长

## 二、调整浪的规则与准则（PDF p117）

- 锯齿形联合调整浪 = 两个或三个锯齿形（双重/三重锯齿）
- 双重三浪（平台形联合）组合：锯齿+平台、平台+锯齿、平台+平台、锯齿+三角形、平台+三角形
- 罕见三重三浪 = 三个平台形
- 双重/三重锯齿**代替**锯齿形；双重/三重三浪**代替**平台形和三角形
- 未见扩散平台形作为联合形成分
- 准则：当锯齿或平台相比前一波浪显得太小（不足以是完整波浪，或相比前一个浪2不足以是完整浪4）时，联合形可能出现

## 三、交替准则（Alternation）

- 核心：**始终预判相似波浪的下一次表现会有所不同**——不要因为上一周期怎么走就认为这次一样
- 推动浪中：浪2若是陡直调整，则预期浪4是横向调整，反之亦然
- 陡直调整：从不含新极端价格（不超越前一推动浪的正统终点）；几乎总是锯齿家族（单/双/三锯齿，或锯齿开始的双重三浪）
- 横向调整：通常包含新极端价格（超越前一推动浪正统终点）；包括平台形、三角形、双重三浪、三重三浪
- 概括：两个调整过程中，**一个会回到或超越前一推动浪终点，另一个不会**
- 斜纹浪**不**在子浪2与浪4之间显示交替（通常两个都是锯齿形）
- 延长浪本身是交替的表现（驱动浪交替其长度；通常浪1短、浪3延长、浪5再短）

## 四、通道（Channeling）

- 推动浪初始通道需**三个参考点**：浪3结束时，过浪1、浪3终点画线，再过浪2画平行线 → 估计浪4边界
- 若浪4未触及平行线就结束：过浪2、浪4终点重画基线，再过浪3顶点画平行线 → 可较准确预测**浪5终点**
- 若浪3异常强劲近乎竖直：改用过**浪1终点**的平行线更有效
- 刻度选择：长期走势用半对数刻度；60分钟等短期用算术刻度
- **锯齿形通道**：连接浪A起点与浪B终点一条线；过浪A终点与浪C终点另一条线；前者形成后，过浪A终点画平行线是研判调整浪确切终点的好办法
- **所有浪级的趋势同时演化**——大浪级第五浪的中浪级第五浪到达上边界时，推动浪可能**两个浪级同时结束**

## 五、翻越与翻下（Throw-over / Throw-under）

- 第五浪在**缩量**中向趋势线运动 → 终点将到或达不到趋势线
- 第五浪接近趋势线时**成交量巨放** → 可能刺穿上边界 = **翻越**
- 翻越点附近：小一级第四浪紧贴上平行线下方横向运动，随后第五浪在成交量巨放中突破
- **翻下**（浪4或浪5中的浪二）常预示翻越的发生
- 翻越以"即刻跌回上通道线下方"的反转来印证
- 下跌市场中发生对称形态

## 六、波浪个性（Wave Personality）

**第一浪**：约一半是筑底过程的一段，常被浪2大幅调整；技术上比前一轮熊市反弹更有建设性，成交量轻度增加、市场广泛性改善；大量卖空显而易见（多数人仍认为大趋势向下）。另50%：从前一调整形成的大底涨起、从下跌失败涨起、或从极度压缩市涨起
**第三浪**：最强、最有活力；广泛性强（多数股票参与）、斜率最陡、常有跳空；此浪中只有第三浪的力量才能让绩差股产生运动
**第五浪**：股票市场中力度比浪3小、广泛性收缩、"价格变化最高速率"通常更低；散户乐观情绪极度高涨；"喷发（blowoff）"行情在股市没有历史；若第五浪延长，其内第五浪也缺乏先前活力
**A浪**：投资界普遍相信只是下一轮上升前的回撤，蜂拥买入；但个股模式出现最初的真正技术性破坏裂缝。**A浪为B浪定调：五浪结构的A → B是锯齿形；三浪结构的A → B是平台形或三角形**
**B浪**：假牛市——牛市陷阱、投机者天堂、散户心态放纵；少数股票参与、常不被其他平均指数印证、技术上极少强势、**几乎注定被C浪完全回撤**。X浪与扩散三角形的D浪有相同特征
**C浪**：毁灭性下跌（B浪被完全回撤）

## 七、研判纪律（原文警示）

- **形态、比率、时间**三者的优先级：形态最优，比率是佐证，时间常"与模式相吻合"
- 波浪理论是"确定可能性而不是必然性的演练"
- 不要强求在**所有浪级同时**看清结构——"恰当的外观"不一定在所有浪级同时显而易见，**专注于最清晰的浪级**
- 清晰度不够时的做法：60分钟困惑就退到日线/周线；周线可能性太多就关注短期
- 数浪出现"强烈情绪推动的不协调比例或畸形模式"时极其危险
- 频繁打破规则的分析者，做的已不是波浪理论
