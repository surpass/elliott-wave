# 模块04 · 数浪实战流程与常见错误

> 综合第一、二章；操盘落地部分为小布基于原文规则的提炼（已标注）

## 一、标准数浪流程（六步）

**第1步 选级别与图表**
- 先看最长周期（周线/月线）确定大结构，再逐级向下
- 浪级由**形态**决定，与价格高低、时间长短无关
- 清晰度原则：某级别看不懂就换级别（60分钟困惑→看日线/周线；周线可能性太多→看短期）
- 原则：**专注最清晰的那个浪级**，不要求所有浪级同时看清

**第2步 找起点与正统终点**
- 起点必须是公认的极端点（正统起点/终点），影线刺穿等非正统极值**不可用作比率基准**
- 多义性存在时，用交替、波浪个性、通道逐步收敛

**第3步 识别模式性质**
- 先判断是**驱动（5浪）**还是**调整（3浪或变体）**
- 铁律：调整浪永远不会是五浪 → 出现五浪形态说明该段尚未结束
- 驱动浪的3个作用浪必为驱动；2、4为调整

**第4步 硬规则校验（不过关即作废该数浪方案）**
- 浪2不越过浪1起点
- 浪3超过浪1终点
- 浪3不是最短
- 浪4不重叠浪1（现货市场）
- 浪1/3/5不全是延长浪
- 浪3细分为推动浪；浪2为锯齿/平台/联合；浪4为锯齿/平台/三角/联合

**第5步 用准则增强置信度**
- 交替：浪2陡直→浪4横向（反之亦然）
- 通道：浪1、3终点连线 + 过浪2平行线 → 定浪4边界；过浪2、4 + 过浪3 → 定浪5目标
- 延长浪：通常在某一个作用浪出现
- 波浪个性：成交量/广泛性/情绪与各浪特征是否吻合
- 比率：回撤 61.8/50/38.2、倍数 1.618 等作**佐证**

**第6步 交叉印证与动态修正**
- 成交量、市场广泛性（ADL等）、相关指数（道氏无印证）
- 其他技术指标（MACD背驰、均线、BOLL）
- 新数据出现后**及时修正**，不硬守原方案

## 二、高位转折的识别信号（反转预警组合）

当出现下列任一，意味着**戏剧性反转近在眼前**：
- 第五浪延长结束
- 缩短的第五浪（未创新高）
- 终结斜纹浪（会聚楔形 + 翻越 + 成交量长钉）
- 三角形调整浪完成后的"冲击"结束
- 第五浪量能/广泛性明显弱于第三浪（背离）
- B浪特征（假牛市、少数股参与、不被印证、几乎注定被C浪完全回撤）

## 三、常见错误（原文及实践总结）

1. **过早标注完整**——尤其中途的三角形："三角形很耗费时间，边界线几乎从不会很快失去作用，要给三角形时间去演化"
2. 用非正统极值做比率基准 → 比率不可靠
3. 只看单一级别，忽略"所有浪级的趋势同时演化"
4. 情绪驱动下接受比例失调/模式畸形的数浪方案——"极其危险"
5. 把B浪当牛市（B浪是骗局；X浪、扩散三角的D浪同理）
6. 把调整浪当成驱动浪结束（调整浪绝不是五浪）
7. 频繁打破硬规则——已不属于波浪理论范畴
8. 在强烈情绪/仓位压力下强行数浪（原书强调"恰当的外观"与专注清晰浪级）

## 四、与其他体系的配合（小布提炼）

| 场景 | 波浪给出 | 缠论给出 | 建议 |
|------|---------|---------|------|
| 判断趋势/盘整 | 驱动浪 vs 调整浪归类 | 趋势 vs 盘整；中枢/笔结构 | 结构以缠论为准（当下性），波浪辅助定性 |
| 目标位 | 斐波那契回撤/倍数、通道 | 中枢区间、前高低点 | 取**多体系重合位** |
| 时间窗 | 斐波那契时间数列（5/8/13/21/34） | 值使门数、级别延续 | 与奇门择时三重过滤 |
| 顶部预警 | 终结斜纹/延长五浪/缩短五浪/B浪 | 顶背驰、三卖 | 任一体系预警即降风险 |
| 失败判定 | 硬规则被违反 → 数浪作废 | 中枢破位/结构破坏 | 优先级：缠论结构 > 波浪假设 |

**仓位纪律**：波浪提供的是"结构假设"，不是持仓理由。破位/超预算必须执行风控，"浪还没走完"不能作为扛单借口。
