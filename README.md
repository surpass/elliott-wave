## 这个 skill 解决什么问题

波浪理论在实战中最大的问题不是"不会数浪"，而是**多义性**：同一段走势可以有多重合法数浪，不同人给出不同结论，谁也不知道该信谁。

本 skill 的作用是当**裁判**，不是当预测器：

| 场景 | 没有 skill 时 | 有 skill 时 |
|:---|:---|:---|
| 一段下跌看起来是五浪 | "应该还没跌完吧？" | **铁律：调整浪永远不会是五浪** → 该段尚未结束，但**它是调整浪的一部分，不是调整浪的结束** |
| 有人说浪4跌进了浪1 | 各凭感觉争吵 | **硬规则：浪4不进入浪1价格区域（不重叠）** → 该数浪方案直接作废 |
| 该在哪里抄底 | "斐波那契61.8%附近" | 先问：**是陡直调整还是横向调整？** 陡直→61.8%/50%；横向→38.2%；引导斜纹之后→78.6% |
| 比率基准取哪个点 | 取最高价/最低价 | **必须以正统终点为基准**，影线刺穿等非正统极值不可用 |

## 使用示例

**规则裁定**
> **Q**：这段下跌数出来是五浪，是不是快见底了？
> **A**：**铁律：调整浪永远不会是五浪**。与大一趋势反向的最初五浪运动，必然是调整浪的一部分，而非调整浪的结束。所以：**它还没走完**——但注意结论的方向，五浪下跌说明还有更低的调整结构，不是见底信号。

**调整类型判别**
> **Q**：这次回调怎么判断买点？
> **A**：先分风格。**陡直调整**（锯齿家族，从不含新极端价格）→ 回撤看 **61.8% 或 50%**。**横向调整**（平台/三角/联合，通常包含回到甚至超过调整起点的运动）→ 回撤看 **38.2%**。若前面是引导斜纹浪，看 **78.6%**。

**平台形三变体**
> **Q**：平台形调整浪有几种？怎么区分？
> **A**：**规则平台**：浪B在浪A起点附近结束，浪C略微超过浪A终点。**扩散平台**（艾略特称"不规则"，实际更常见）：浪B超过浪A起点，浪C远远超过浪A终点。**顺势平台**（罕见）：浪B超过浪A起点，但浪C走不完全程、达不到浪A终点。位置特征：**浪4常走平台形，浪2很少**。

**组合结构约束**
> **Q**：联合型调整浪能包含几个锯齿？
> **A**：**最多一个锯齿形、最多一个三角形**，且三角形只能作为最后一浪。双重三浪的合法组合：锯齿+平台、平台+锯齿、平台+平台、锯齿+三角、平台+三角；罕见三重三浪 = 三个平台形。

**顶部识别**
> **Q**：怎么判断这波涨到头了？
> **A**：以下任一出现即意味着**戏剧性反转近在眼前**：第五浪延长结束 / 缩短的第五浪（未创新高）/ 终结斜纹浪（会聚楔形 + 翻越 + 成交量长钉）/ 三角形完成后的"冲击"结束 / 第五浪量能与广泛性明显弱于第三浪 / B浪特征（假牛市、少数股参与、不被其他指数印证）。

## 核心知识体系

### 波浪速查表

| 模式 | 结构 | 关键特征 |
|------|------|---------|
| 推动浪 Impulse | 5-3-5-3-5 | 浪4不重叠浪1；浪3非最短 |
| 终结斜纹浪 Ending Diagonal | 3-3-3-3-3 | 浪5或C浪位置；会聚楔形+翻越+成交量长钉；之后陡直回撤至少回到起点 |
| 引导斜纹浪 Leading Diagonal | 3-3-3-3-3 | 浪1或锯齿A浪位置；之后深度回撤（≈78.6%） |
| 锯齿形 Zigzag | 5-3-5 | 单/双/三锯齿；陡直调整代表 |
| 平台形 Flat | 3-3-5 | 规则/扩散（更常见）/顺势；常作浪4 |
| 三角形 Triangle | 3-3-3-3-3 | **仅出现在最后一个作用浪之前**；横向+缩量；之后"冲击" |
| 联合型 Combination | W-X-Y(-Z) | 双重三浪/三重三浪；≤1锯齿、≤1三角形 |

### 规则 vs 准则（最重要的一刀）

```
规则（Rules）—— 不容漠视，违反即作废：
  浪2永远不会运动过浪1的起点
  浪3总是运动过浪1的终点
  浪3永远不会是最短的一浪
  浪1、3、5不会都是延长浪
  浪4不会进入浪1的价格区域（不重叠，现货市场）
  浪3总是细分成一个推动浪
  浪2/浪4 只能细分成指定的调整类型

准则（Guidelines）—— 典型特征，非必然：
  交替：浪2与浪4的调整模式不同
  通道：过浪1、3画线 + 过浪2画平行线 → 定浪4边界
  延长：1/3/5中通常有一个延长（浪3最常见）
  缩短：浪5有时不创新高

研判优先级：形态 > 比率 > 时间（比率是佐证，不是决策依据）
```

### 数浪六步工作流

```
1. 定浪级  → 从最长周期图开始，浪级由形态定（非价格/时间长度）
2. 识模式  → 驱动5浪 vs 调整3浪；调整浪永远不会是五浪
3. 验规则  → 硬门槛，违反即作废该数浪方案
4. 用准则  → 交替、通道、延长浪、波浪个性
5. 算目标  → 回撤 61.8/50/38.2 + 倍数 1.618 + 斐波那契时间
6. 交叉印证 → 成交量、广泛性、相关指数、MACD背驰；动态修正
```

### 调整类型 → 回撤位对照

| 调整类型 | 典型回撤 | 常见位置 |
|---------|---------|---------|
| 陡直调整 | **61.8% 或 50%** | 推动浪浪2、大一级锯齿形的浪B、多重锯齿的浪X |
| 引导斜纹浪之后 | **78.6%（√Φ）** | 浪1位置的引导斜纹之后 |
| 横向调整 | **38.2%** | 尤其浪4 |

> ⚠️ 比率必须以**正统终点**为基准；基于非正统极端价格（如影线刺穿）的比率不可靠。

## 边界与风控（原书精神）

1. 波浪理论是"确定可能性而不是必然性的演练"——**不给确定性结论**
2. **多义性**：同一走势可有多重合法数浪；必须用交替/个性/通道收敛，收敛不了就说明浪级选错
3. 比率必须以**正统终点**为基准，非正统极值的比率不可靠
4. 所有浪级的趋势**同时**演化，不可只看一个级别
5. 数浪错误最常见的死法是"**过早标注完整**"（尤其中途的三角形）
6. 频繁打破硬规则的分析者，做的已不是波浪理论
